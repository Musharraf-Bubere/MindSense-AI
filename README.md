# 🌟 Project Overview

MindSense AI is a web-based **Mental Health Risk Prediction System** that uses **Machine Learning** to estimate whether a user's assessment falls into a **Low Risk** or **High Risk** mental health category.

Unlike traditional AI systems that may provide predictions without clear explanations, MindSense AI integrates **Explainable Artificial Intelligence (XAI)** using **SHAP (SHapley Additive exPlanations)** to provide transparent and interpretable predictions.

The system uses **Logistic Regression** for binary classification and SHAP to explain the factors influencing individual predictions.

The application also provides personalized recommendations, assessment history, interactive analytics, and downloadable PDF reports.

### ✨ Core Capabilities

- 🤖 AI-Based Mental Health Risk Prediction
- 🧠 Explainable AI using SHAP
- 💙 Personalized Mental Health Recommendations
- 📊 Interactive Analytics Dashboard
- 🗄 Assessment History using SQLite
- 📈 SHAP Feature Importance Visualization
- 📄 Downloadable PDF Reports
- 🌐 Cloud Deployment

> ⚠️ **Important:** MindSense AI is an educational and research-oriented project designed for early risk assessment and awareness. It is **not a medical diagnostic system** and should not replace a qualified psychologist, psychiatrist, doctor, or other healthcare professional.

# 🧠 Machine Learning Model

## 🔬 Algorithm

MindSense AI uses **Logistic Regression** as the final machine learning model.

Logistic Regression was selected because the project performs **binary classification**.

The model estimates the probability of the positive class and classifies the assessment into:

```text
🟢 Low Risk
      OR
🔴 High Risk
```

## 💡 Why Logistic Regression?

Logistic Regression was selected because it:

- ✅ Is suitable for binary classification
- ✅ Produces probability estimates
- ✅ Is computationally efficient
- ✅ Provides fast training and prediction
- ✅ Works well with structured/tabular data
- ✅ Produces interpretable results
- ✅ Is compatible with Explainable AI techniques such as SHAP

---

# 📊 Model Evaluation

The final Logistic Regression model demonstrated strong performance for **depression prediction** on the held-out test dataset.

| Metric | Result |
|---|---:|
| 🎯 Accuracy | **99%** |
| 🎯 Precision (Depression) | **96%** |
| 🎯 Recall (Depression) | **95%** |
| 🎯 F1-Score (Depression) | **96%** |
| 📈 ROC-AUC | **0.999** |
| 📊 PR-AUC | **0.996** |

## 📌 Test Set Performance

The model correctly classified:

### ✅ 505 out of 512 test samples

with only:

### ❌ 7 misclassifications

## 🔲 Confusion Matrix

| | Predicted No Risk | Predicted High Risk |
|---|---:|---:|
| **Actual No Risk** | 426 | 3 |
| **Actual High Risk** | 4 | 79 |

The evaluation results indicate that the Logistic Regression model performed strongly on the evaluation dataset and was able to distinguish between individuals with and without depression.

> ⚠️ High evaluation performance does not imply clinical validity. The model was trained and evaluated using a specific dataset, and its performance on external datasets may differ.

---

# ⚠️ Model Limitations

Despite its strong evaluation performance, the Logistic Regression model has several limitations:

- The model assumes a linear relationship between the input features and the target variable.
- A small number of false negative predictions still exist, which may be important in healthcare-related applications.
- The model was trained and evaluated using a single dataset, so performance on external datasets may differ.
- The model predicts depression risk based on the available features.
- The system should not be considered a replacement for professional clinical diagnosis.

# 🔬 Explainable AI — SHAP

MindSense AI uses **SHAP (SHapley Additive exPlanations)** to explain model predictions.

SHAP provides feature-level explanations for individual predictions.

## ❓ What Does SHAP Explain?

SHAP helps answer:

> **"Which features influenced the model's prediction and in what direction?"**

## 🟢 Positive SHAP Contribution

A positive SHAP contribution pushes the prediction toward:

**Higher probability of Depression / High Risk**

## 🔵 Negative SHAP Contribution

A negative SHAP contribution pushes the prediction toward:

**Lower probability of Depression / High Risk**

## 📊 SHAP Explanation Types

### 🌍 Global Explanation

Helps understand which features are generally important across the dataset.

### 👤 Local Explanation

Explains why the model made a prediction for a specific individual assessment.

SHAP improves **model interpretability and transparency**, but it does not improve the underlying model's accuracy.
